# Desafio 14
Este proyecto es un desafío práctico correspondiente al curso de Desarrollo Web Frontend del PEAM (UNSE).

El objetivo del trabajo es programar la renderización dinámica de un catálogo de propiedades inmobiliarias distribuidas en secciones de venta y alquiler, aplicando componentes visuales e íconos que se adaptan automáticamente según las características de cada vivienda.

Para su construcción se utilizaron tecnologías como HTML, CSS (utilizando el sistema de grillas y clases de utilidad de Bootstrap) y JavaScript. El enfoque técnico se centró en la gestión de estructuras de datos mediante arreglos de objetos. Se implementaron ciclos iterativos (for) combinados con interpolación de plantillas literales (template strings) e .innerHTML para maquetar y volcar las tarjetas en el DOM dinámicamente. Asimismo, se emplearon estructuras condicionales para evaluar atributos booleanos (como permisos de mascotas o zonas de fumadores) y lógica de control para limitar la carga de elementos en la vista principal.
